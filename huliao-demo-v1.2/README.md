# 胡了吗 Demo v1.2.0

这是黑客松 MVP 的本地模型识别 Demo v1.2，基于 v1.1.0 新建，不覆盖原版本。

## 项目口径

胡牌后拍一张牌面，AI识别牌型并按地区规则自动算分，同时记录战绩，帮助麻将玩家少争论、快结算、可复盘。

## MVP闭环

1. 选择地区规则和基础点数
2. 上传麻将牌面图片
3. 调用 YOLO `best.pt` 识别麻将牌
4. 输出番种明细、点数和金额
5. 保存单局账单
6. 查看历史记录和轻量复盘

## v1.2变化

- 接入作者训练好的 YOLO 模型 `models/best.pt`
- 新增 Flask 识别服务 `app.py`
- 前端上传图片后调用 `/api/recognize`
- 输出识别出的麻将牌、检测数量、类别和置信度
- 保留 v1.1 的样例兜底，防止现场模型服务异常

## 运行方式

先安装依赖：

```bash
python3 -m pip install -r requirements.txt
```

启动本地服务：

```bash
python3 app.py
```

浏览器打开：

```text
http://127.0.0.1:5120
```

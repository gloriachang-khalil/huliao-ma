# 胡了吗 Demo v1.0.0

这是黑客松 MVP 的静态 H5 Demo，保留为版本 1。

## 项目口径

胡牌后拍一张牌面，AI识别牌型并按地区规则自动算分，同时记录战绩，帮助麻将玩家少争论、快结算、可复盘。

## MVP闭环

1. 选择地区规则和基础点数
2. 上传或使用稳定样例牌面
3. 识别牌型
4. 输出番种明细、点数和金额
5. 保存单局账单
6. 查看历史记录和轻量复盘

## 运行方式

直接用浏览器打开 `index.html` 即可。

# 胡了吗 Demo v2.3

这是基于移动端内测反馈重新整理的信息架构版本，主线进一步聚焦为“首页创建/加入牌局、记忆局完成结算、我的承载复杂功能”。

## 文件

- `index.html`：Demo 主页面
- `styles.css`：视觉与响应式布局
- `script.js`：跳转流程、单局结算、AI 裁判样例、总账复盘

## v2.3 调整

- 底部导航精简为：首页、记忆局、我的。
- 首页只保留创建牌局、加入牌局两个核心入口。
- 创建牌局拆分为基础信息页和房间生成页，手机端不再先显示二维码。
- 房间生成页和房间面板增加“长按下载分享”按钮。
- 麻将桌、固定牌友圈、本周排行、房间、AI 裁判、总账、历史统一收纳到“我的”。
- 记忆局沿用原单局结算逻辑，点击“进入牌局房间”后直接进入记忆局。
- 0 局时高光状态显示“待产生”，避免误导。

## 演示路径

1. 首页点击“创建牌局”或“加入牌局”
2. 创建牌局先填写地区、规则、底分、封顶、圈数和玩家信息
3. 点击“生成房间”，进入房间码和二维码页面
4. 点击“进入牌局房间”，进入记忆局完成单局结算
5. 在“我的”中查看房间面板、AI 裁判、总账复盘和历史战绩

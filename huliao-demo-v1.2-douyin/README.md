# 胡了吗 Demo v1.2.1 互动空间版

这是黑客松 MVP 的抖音互动空间提交版，基于 v1.2.0 新建，不覆盖本地 YOLO 演示版本。

## 项目口径

胡牌后拍一张牌面，AI识别牌型并按地区规则自动算分，同时记录战绩，帮助麻将玩家少争论、快结算、可复盘。

## MVP闭环

1. 选择地区规则和基础点数
2. 上传麻将牌面图片或使用稳定样例
3. 通过离线识别候选和人工校正确认麻将牌
4. 输出番种明细、点数和金额
5. 保存单局账单
6. 查看历史记录和轻量复盘

## 互动空间版变化

- 移除 Flask 服务和 YOLO 模型文件
- 移除 `/api/recognize` 网络/后端调用
- 保留上传预览、识别校正、番种明细、账单保存和轻量复盘
- 包体远低于 8MB，适合交流赛互动空间 Demo

## 运行方式

直接用浏览器打开 `index.html` 即可。

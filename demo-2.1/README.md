# 胡了吗 Demo v2.1

这是基于导师反馈重新整理的黑客松演示版本，主线从“单人 AI 拍照算分”调整为“四人共同开局、记分、结算、复盘”，AI 识别作为复杂牌面的辅助裁判入口。

## 文件

- `index.html`：Demo 主页面
- `styles.css`：视觉与响应式布局
- `script.js`：跳转流程、单局结算、AI 裁判样例、总账复盘

## v2.1 调整

- 增加底部常驻导航：首页、房间、记一局、总账、历史，手机端不用到处找按钮。
- 新牌局默认从第 1 局开始，创建房间会清空本场积分、单局流水和 AI 争议记录。
- 使用新的本地缓存 key，避免手机端沿用 v2.0 的旧局数缓存。
- 历史页新增“本场单局记录”，不用先保存整场也能回看今天刚记过的每一局。

## 演示路径

1. 首页点击“创建牌局”或“加入牌局”
2. 创建房间，生成房间码和二维码
3. 进入牌局房间，查看四人积分面板
4. 点击“单局结算”，选择赢家、付款方式、番型、倍数或直接输入金额
5. 遇到争议时进入“AI 裁判”，查看牌型、番数、依据和置信度
6. 进入“查看总账”，生成整场结算和局后分享图
